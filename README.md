# Blackboard Studio

Turn any image into 16 × 16 Supplementaries blackboard plans for Minecraft. Runs entirely in your browser; nothing is uploaded.

**Open the app:** https://kapix789.github.io/cld/

Or download [`blackboard-studio/Blackboard-Studio.html`](blackboard-studio/Blackboard-Studio.html) and open it directly; it works offline.

Source, tests and build instructions are in [`blackboard-studio/`](blackboard-studio/README.md).
