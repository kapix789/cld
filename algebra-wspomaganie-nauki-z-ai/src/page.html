Przepis na równanie macierzowe

  1. Rozpisz nawiasy z T i −1 — kolejność się odwraca.
  2. Przenieś wyrazy z X na lewo, bez X na prawo (zmiana znaku).
  3. Jeśli X jest kilka razy — wyciągnij go przed nawias (patrz niżej).
  4. To, co stoi przed X, usuwasz mnożąc obie strony z lewej przez odwrotność.
  5. To, co stoi za X, usuwasz mnożąc obie strony z prawej przez odwrotność.
  6. Dopiero teraz podstawiasz liczby: liczysz odwrotną, potem iloczyny.
Najczęstsze błędy
  • Mnożenie jednej strony z lewej, a drugiej z prawej. Zawsze ta sama strona!
  • (AB)−1 ≠ A−1B−1 — poprawnie B−1A−1.
  • AX − X = (A − 1)X — źle! Od macierzy nie odejmiesz liczby. Poprawnie (A − I)X.
  • „Dzielenie” przez macierz nie istnieje — tylko mnożenie przez odwrotną.
⫽

Recipe for a matrix equation

  1. Expand the brackets with T and −1 — the order reverses.
  2. Move the terms with X to the left and those without X to the right (the sign changes).
  3. If X appears several times — factor it out (see below).
  4. Whatever stands in front of X you remove by multiplying both sides on the left by its inverse.
  5. Whatever stands after X you remove by multiplying both sides on the right by its inverse.
  6. Only now substitute the numbers: compute the inverse, then the products.
Most common mistakes
  • Multiplying one side on the left and the other on the right. Always the same side!
  • (AB)−1 ≠ A−1B−1 — correct is B−1A−1.
  • AX − X = (A − 1)X — wrong! You cannot subtract a number from a matrix. Correct is (A − I)X.
  • “Dividing” by a matrix does not exist — only multiplying by the inverse.
⟧

Macierz odwrotna — metoda Gaussa

Zapisz obok siebie [A | I] i operacjami na wierszach doprowadź lewą część do I. Po prawej wyjdzie A−1.

Dozwolone operacje (zawsze na całym wierszu, po obu stronach kreski):

  • w1 ↔ w2 — zamiana wierszy
  • w1 : 3 — podzielenie wiersza przez liczbę ≠ 0
  • w2 − 3w1 — od wiersza 2 odejmij 3 × wiersz 1
Kolejność: kolumna po kolumnie. W kolumnie robisz „1” na przekątnej, potem zera nad i pod nią. Wygodnie zacząć od wiersza, który ma w danej kolumnie 1 lub −1.
Kontrola: A·A−1 musi dać I.
⫽

Inverse matrix — Gaussian elimination

Write [A | I] side by side and use row operations to turn the left part into I. A−1 appears on the right.

Allowed operations (always on the whole row, on both sides of the bar):

  • R1 ↔ R2 — swap two rows
  • R1 : 3 — divide a row by a number ≠ 0
  • R2 − 3R1 — subtract 3 × row 1 from row 2
Order: column by column. In each column make a “1” on the diagonal, then zeros above and below it. It is convenient to start from a row that has 1 or −1 in that column.
Check: A·A−1 must give I.

Równanie macierzowe przez niewiadome

Gdy X nie da się wyciągnąć przed nawias (AX + XB, AX = XA, X razem z XT) albo macierz do odwrócenia nie jest kwadratowa lub odwracalna — liczysz na elementach:

  1. Ustal wymiar X z wymiarów działań i zapisz X = xyzt.
  2. Wymnóż obie strony — elementy wyjdą jako wyrażenia z x, y, z, t.
  3. Macierze są równe, gdy są równe wszystkie elementy — porównaj je i dostaniesz układ równań.
  4. Rozwiąż układ (Gauss). Może wyjść jedno X, nieskończenie wiele albo żadne.

⫽

Matrix equation using unknowns

When X cannot be factored out (AX + XB, AX = XA, X together with XT) or the matrix to invert is not square or not invertible — compute with the entries:

  1. Find the size of X from the sizes in the operations and write X = xyzt.
  2. Multiply out both sides — the entries become expressions in x, y, z, t.
  3. Matrices are equal when all their entries are equal — compare them and you get a system of equations.
  4. Solve the system (Gauss). There may be one X, infinitely many or none.

Example: all X that commute with A = 1101, i.e. AX = XA:

Ile rozwiązań? Twierdzenie Kroneckera–Capellego

n — liczba niewiadomych, rz — rząd (liczba niezerowych wierszy po eliminacji Gaussa).

  • rz A = rz [A | B] = n → dokładnie jedno rozwiązanie (układ oznaczony).
  • rz A = rz [A | B] = r < n → nieskończenie wiele rozwiązań, zależnych od n − r parametrów.
  • rz A < rz [A | B] → brak rozwiązań (układ sprzeczny).
⫽

How many solutions? The Rouché–Capelli theorem

n — the number of unknowns, rank — the number of nonzero rows after Gaussian elimination.

  • rank A = rank [A | B] = n → exactly one solution.
  • rank A = rank [A | B] = r < n → infinitely many solutions, depending on n − r parameters.
  • rank A < rank [A | B] → no solutions (inconsistent system).

Metoda Gaussa dla układu

  1. Zapisz macierz rozszerzoną [A | B].
  2. Operacjami na wierszach (tymi samymi co przy A−1) zrób kolumna po kolumnie jedynki na „schodkach” i zera nad nimi i pod nimi.
  3. Wiersz [0 … 0 | 0], czyli 0 = 0 — skreśl. Wiersz [0 … 0 | 5], czyli 0 = 5 — układ jest sprzeczny.
  4. Niewiadome w kolumnach bez schodka są swobodne (dowolne liczby). Pozostałe wyraź przez nie.
Zapis rozwiązania ogólnego: x = 2 − 3z,  y = 1 + z,  z ∈ ℝ. Każda liczba podstawiona za z daje jedno rozwiązanie.
⫽

Gaussian elimination for a system

  1. Write the augmented matrix [A | B].
  2. With row operations (the same as for A−1) make, column by column, ones on the “steps” and zeros above and below them.
  3. A row [0 … 0 | 0], i.e. 0 = 0 — cross it out. A row [0 … 0 | 5], i.e. 0 = 5 — the system is inconsistent.
  4. The unknowns in columns without a pivot are free (any numbers). Express the others in terms of them.
Writing the general solution: x = 2 − 3z,  y = 1 + z,  z ∈ ℝ. Every number substituted for z gives one solution.
⟧

Metoda macierzowa i wzory Cramera

Obie działają tylko dla układu kwadratowego z det A ≠ 0. Gdy det A = 0, układ jest sprzeczny albo ma nieskończenie wiele rozwiązań — rozstrzyga Gauss.

  • Macierzowa: AX = B ⇒ X = A−1B. Mnożysz z lewej — BA−1 to błąd (i zwykle nawet się nie da).
  • Cramer: W = det A, a Wx to wyznacznik A, w którym kolumnę przy x zastępujesz kolumną wyrazów wolnych. Wtedy x = Wx / W, y = Wy / W …
  • Wyznacznik 2×2: abcd = ad − bc.
  • Wyznacznik 3×3 (Sarrus): trzy iloczyny po przekątnych „w prawo w dół” z plusem, trzy „w lewo w dół” z minusem: a11a22a33 + a12a23a31 + a13a21a32 − a13a22a31 − a11a23a32 − a12a21a33.
⫽

The matrix method and Cramer’s rule

Both work only for a square system with det A ≠ 0. When det A = 0, the system is inconsistent or has infinitely many solutions — Gaussian elimination decides.

  • Matrix method: AX = B ⇒ X = A−1B. You multiply on the left — BA−1 is a mistake (and usually not even possible).
  • Cramer: D = det A, and Dx is the determinant of A with the column of x replaced by the column of constants. Then x = Dx / D, y = Dy / D …
  • 2×2 determinant: abcd = ad − bc.
  • 3×3 determinant (Sarrus): three diagonal products going “down to the right” with a plus, three going “down to the left” with a minus: a11a22a33 + a12a23a31 + a13a21a32 − a13a22a31 − a11a23a32 − a12a21a33.

Wyznaczniki — własności

  • det(AB) = det A · det B    det(AT) = det A    det(A−1) = 1 / det A
  • det(kA) = kn · det A dla macierzy n×n (liczba wychodzi z każdego wiersza!)
  • det(A + B) ≠ det A + det B — tego nie ma.
  • Zamiana dwóch wierszy (kolumn) zmienia znak wyznacznika.
  • Dodanie do wiersza wielokrotności innego wiersza nie zmienia wyznacznika — tak robi się zera przed Laplace'em.
  • Wiersz zer albo dwa proporcjonalne wiersze → det = 0.
  • Macierz trójkątna: det = iloczyn liczb na przekątnej.
  • A jest odwracalna ⇔ det A ≠ 0.
⫽

Determinants — properties

  • det(AB) = det A · det B    det(AT) = det A    det(A−1) = 1 / det A
  • det(kA) = kn · det A for an n×n matrix (the number comes out of every row!)
  • det(A + B) ≠ det A + det B — there is no such rule.
  • Swapping two rows (columns) changes the sign of the determinant.
  • Adding a multiple of one row to another does not change the determinant — this is how you make zeros before Laplace expansion.
  • A row of zeros or two proportional rows → det = 0.
  • Triangular matrix: det = the product of the numbers on the diagonal.
  • A is invertible ⇔ det A ≠ 0.

Rząd macierzy

  • Rząd = liczba niezerowych wierszy po sprowadzeniu macierzy do postaci schodkowej (Gauss, zera pod elementami głównymi).
  • Operacje na wierszach (i kolumnach) nie zmieniają rzędu.
  • rz A ≤ min(liczba wierszy, liczba kolumn). Dla macierzy kwadratowej n×n: rz A = n ⇔ det A ≠ 0.
⫽

Rank of a matrix

  • Rank = the number of nonzero rows after reducing the matrix to row echelon form (Gauss, zeros below the pivots).
  • Row (and column) operations do not change the rank.
  • rank A ≤ min(number of rows, number of columns). For a square n×n matrix: rank A = n ⇔ det A ≠ 0.

Układ z parametrem — przepis

  1. Policz wyznacznik główny W(a), traktując a jak zwykłą liczbę.
  2. Rozwiąż W(a) = 0. Dla pozostałych a układ ma dokładnie jedno rozwiązanie.
  3. Każdą wartość z W = 0 podstaw do układu i rozstrzygnij Gaussem (albo rzędami): sprzeczny czy nieskończenie wiele rozwiązań.
  4. Odpowiedź zbierz w punktach: dla a ∉ {…}, dla a = …, dla a = ….
⫽

System with a parameter — recipe

  1. Compute the main determinant D(a), treating a as an ordinary number.
  2. Solve D(a) = 0. For all other a the system has exactly one solution.
  3. Substitute each value with D = 0 into the system and decide with Gaussian elimination (or ranks): inconsistent or infinitely many solutions.
  4. Collect the answer in points: for a ∉ {…}, for a = …, for a = ….

Działania

  • Dodawanie: tylko te same wymiary, element po elemencie.
  • Mnożenie A·B: (m×n)·(n×p) = m×p. Element cij = i-ty wiersz A „razy” j-ta kolumna B.
  • AB ≠ BA — kolejność ma znaczenie.
  • Transpozycja: wiersze stają się kolumnami; m×n → n×m.
  • A2 = A·A (macierzowo, nie każdy element do kwadratu!)
⫽

Operations

  • Addition: only equal sizes, entry by entry.
  • Multiplication A·B: (m×n)·(n×p) = m×p. The entry cij = row i of A “times” column j of B.
  • AB ≠ BA — the order matters.
  • Transpose: rows become columns; m×n → n×m.
  • A2 = A·A (as matrices, not every entry squared!)
